## 2. Logic Chain

1. **Shared Form Template Guarantees Consistency** (Ref: Section 1.1):
   Because `renderModal(catalogState)` renders both Add and Edit modals based solely on `this.modalMode`, replacing `#form-prod-image` with our new image upload component automatically enforces 100% layout and visual consistency between the two forms.
2. **Preserving Form Data via Immediate Upload** (Ref: Section 1.2):
   If we upload the image immediately upon file selection or drop, we avoid having to re-render the entire modal DOM (which would wipe out other inputs the admin already typed, like Name, Brand, Price, etc.). Instead:
   - File selection updates the image preview directly via a local Blob URL (`URL.createObjectURL(file)`).
   - The file is immediately uploaded to `POST /api/products/upload` via `store.uploadProductImage(file)`.
   - The server-returned URL (e.g., `/assets/images/products/lancome-1730784900-a1b2c3d4.webp`) is written into a hidden input `<input type="hidden" id="form-prod-image" name="image" value="...">`.
   - On form submit, `form.image.value` contains the finalized server URL, requiring zero changes to the existing `payload` construction logic!
3. **Aspect Ratio Enforcement**:
   Luxury beauty e-commerce imagery requires standardized square framing (1:1 ratio, 140x140px) with `object-fit: cover` and frosted borders, matching the storefront cards and detail view media columns.
4. **Direct Image Removal Support** (Ref: Section 1.5):
   Clicking "Remove Image" clears the preview, resets the file input, hides the remove button, and sets `#form-prod-image.value = ""`. When the admin saves, the controller sets `product.images = []`, fulfilling the requirement to remove existing images.

---

## 3. Caveats

- **Network Mode**: Investigation was conducted locally; no external dependencies or CDNs are required.
- **Backend Endpoint Dependency**: Frontend relies on `POST /api/products/upload` accepting `multipart/form-data` with field `image` and returning `{ success: true, imageUrl: '/assets/images/products/<filename>' }` (being implemented by backend worker per `teamwork_explorer_m5_refine_2`).
- **Memory Management**: When creating preview URLs with `URL.createObjectURL`, ensure `URL.revokeObjectURL` is invoked when a new image is selected or when the modal is closed/cancelled to avoid client memory leakage.

Add the following method to `ApiClient` class (e.g. right before `createProduct` at line 230):

```javascript
  /**
   * Upload product image file (Admin only)
   * @param {File|FormData} fileOrFormData - Image file or pre-constructed FormData
   * @returns {Promise<{ success: boolean, data: { success: boolean, imageUrl: string, message?: string }, error: string|null, status: number }>}
   */
  async uploadProductImage(fileOrFormData) {
    let formData;
    if (fileOrFormData instanceof FormData) {
      formData = fileOrFormData;
    } else {
      formData = new FormData();
      formData.append('image', fileOrFormData);
    }

    return this.request('/products/upload', {
      method: 'POST',
      body: formData,
    });
  }
```

### 4.2 Changes to `public/js/store.js`

Add the following method to `Store` class (e.g. at line 1046, under `Admin Operations & Reactive State`):

```javascript
  /**
   * Upload product image file via admin portal
   * @param {File|FormData} fileOrFormData - Image file or FormData
   * @returns {Promise<string>} Uploaded image URL (e.g. '/assets/images/products/...')
   */
  async uploadProductImage(fileOrFormData) {
    this.setState('admin', { isSaving: true, error: null });
    const res = await api.uploadProductImage(fileOrFormData);
    this.setState('admin', { isSaving: false });

    if (res.success && res.data && res.data.imageUrl) {
      return res.data.imageUrl;
    } else {
      const msg = res.error || res.data?.message || 'Failed to upload product image';
      this.showToast(msg, 'error');
      this.setState('admin', { error: msg });
      throw new Error(msg);
    }
  }
```

#### 4.3.4 Add Helper Methods to `AdminDashboardComponent`:
```javascript
  async handleImageFileSelection(file) {
    const validMimes = ['image/jpeg', 'image/jpg', 'image/png', 'image/webp', 'image/gif'];
    const maxSizeBytes = 5 * 1024 * 1024; // 5 MB

    const previewImg = this.container.querySelector('#image-preview-img');
    const placeholder = this.container.querySelector('#image-preview-placeholder');
    const previewBox = this.container.querySelector('#image-preview-box');
    const removeBtn = this.container.querySelector('#btn-remove-image');
    const statusEl = this.container.querySelector('#image-upload-status');
    const hiddenInput = this.container.querySelector('#form-prod-image');
    const errorEl = this.container.querySelector('#form-prod-error');
    const submitBtn = this.container.querySelector('#btn-submit-product');

    if (!validMimes.includes(file.type.toLowerCase())) {
      store.showToast('Please select a valid image file (JPEG, PNG, WebP, GIF)', 'error');
      if (errorEl) {
        errorEl.textContent = 'Invalid file type. Please select a JPEG, PNG, WebP, or GIF image.';
        errorEl.classList.remove('hidden');
      }
      return;
    }

    if (file.size > maxSizeBytes) {
      store.showToast('Image file size exceeds the 5MB limit', 'error');
      if (errorEl) {
        errorEl.textContent = `File size (${(file.size / (1024 * 1024)).toFixed(1)}MB) exceeds maximum limit of 5MB.`;
        errorEl.classList.remove('hidden');
      }
      return;
    }

    if (errorEl) {
      errorEl.classList.add('hidden');
    }

    // 1. Show immediate local preview
    if (this.currentPreviewBlobUrl) {
      URL.revokeObjectURL(this.currentPreviewBlobUrl);
    }
    this.currentPreviewBlobUrl = URL.createObjectURL(file);

    if (previewImg) {
      previewImg.src = this.currentPreviewBlobUrl;
      previewImg.classList.remove('hidden');
    }
    if (placeholder) {
      placeholder.classList.add('hidden');
    }
    if (previewBox) {
      previewBox.classList.add('has-image');
      previewBox.classList.remove('empty');
    }
    if (removeBtn) {
      removeBtn.classList.remove('hidden');
    }

    // 2. Upload file immediately to backend
    if (statusEl) {
      statusEl.className = 'image-upload-status status-uploading';
      statusEl.innerHTML = '<span class="status-spinner">⏳</span> <span class="status-text">Uploading image to vault...</span>';
      statusEl.classList.remove('hidden');
    }

    this.isUploadingImage = true;
    if (submitBtn) {
      submitBtn.disabled = true;
    }

    try {
      const uploadedUrl = await store.uploadProductImage(file);
      if (hiddenInput) {
        hiddenInput.value = uploadedUrl;
      }
      if (statusEl) {
        statusEl.className = 'image-upload-status status-success';
        statusEl.innerHTML = '<span class="status-icon">✓</span> <span class="status-text">Image uploaded and attached</span>';
      }
      store.showToast('Product image uploaded successfully', 'success');
    } catch (err) {
      if (statusEl) {
        statusEl.className = 'image-upload-status status-error';
        statusEl.innerHTML = `<span class="status-icon">⚠️</span> <span class="status-text">Upload failed: ${escapeHtml(err.message || 'Error')}</span>`;
      }
    } finally {
      this.isUploadingImage = false;
      if (submitBtn) {
        submitBtn.disabled = false;
      }
    }
  }

  handleImageRemoval() {
    if (this.currentPreviewBlobUrl) {
      URL.revokeObjectURL(this.currentPreviewBlobUrl);
      this.currentPreviewBlobUrl = null;
    }

    const previewImg = this.container.querySelector('#image-preview-img');
    const placeholder = this.container.querySelector('#image-preview-placeholder');
    const previewBox = this.container.querySelector('#image-preview-box');
    const removeBtn = this.container.querySelector('#btn-remove-image');
    const statusEl = this.container.querySelector('#image-upload-status');
    const hiddenInput = this.container.querySelector('#form-prod-image');
    const fileInput = this.container.querySelector('#form-prod-file-input');

    if (previewImg) {
      previewImg.src = '';
      previewImg.classList.add('hidden');
    }
    if (placeholder) {
      placeholder.classList.remove('hidden');
    }
    if (previewBox) {
      previewBox.classList.remove('has-image');
      previewBox.classList.add('empty');
    }
    if (removeBtn) {
      removeBtn.classList.add('hidden');
    }
    if (fileInput) {
      fileInput.value = '';
    }
    if (hiddenInput) {
      hiddenInput.value = '';
    }
    if (statusEl) {
      statusEl.className = 'image-upload-status status-info';
      statusEl.innerHTML = '<span class="status-icon">ℹ️</span> <span class="status-text">Image removed. Save changes to update.</span>';
      statusEl.classList.remove('hidden');
    }
  }
```

## 5. Verification Method

To independently verify the implementation:

1. **Unit & API Testing**:
   Execute the automated test suite:
   ```powershell
   npm test
   ```
   Ensure all test suites pass, specifically `tests/admin.test.js` or `tests/upload.test.js`.

2. **Frontend UI Flow Testing**:
   - Start the development server (`npm start` or `npm run dev`).
   - Open browser to `http://localhost:3000/#/admin` authenticated as an administrator.
   - **Test Add Product Modal**:
     - Click `+ Add New Product`.
     - Verify the image upload dropzone is rendered with glassmorphism styling and the placeholder shows "No image selected".
     - Select an image file (e.g., JPEG/PNG/WebP). Verify the 1:1 preview appears immediately and the upload status indicates success.
     - Click "Remove Image". Verify the image preview disappears, placeholder returns, and the remove button hides.
     - Re-select a file, fill in required fields, and click "Create Product". Verify the product is saved and its thumbnail appears in the table.
   - **Test Edit Product Modal**:
     - Click `✏️ Edit` on any product that has an image.
     - Verify the current image appears in the 1:1 preview box, and the "Remove Image" button is visible.
     - Click "Remove Image", save the product, and verify the product in the table now shows the default placeholder image.
     - Edit another product, upload a replacement image via drag-and-drop onto the dropzone, and save. Verify the new image displays.
   - **Test Invalid File & Size Limit**:
     - Attempt to select a `.txt` or `.exe` file; verify toast and error message reject it.
     - Attempt to select a file > 5MB; verify size limit warning.

3. **Invalidation Conditions**:
   - If the backend returns a different field name than `imageUrl` (e.g. `image` or `path`), verify that `res.data.imageUrl || res.data.image || res.data.url` fallback is applied.
   - If the modal DOM is re-rendered during file selection, check that inputs are not reset (our event handlers deliberately manipulate the preview DOM directly to preserve all unsaved inputs).
